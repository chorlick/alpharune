Self-Play (Phase 8 — REINFORCE)
=====================================
# Prereqs: models/{miss_fortune,rengar}/v001.{pt,onnx} exist from the
# supervised baselines above. Each iteration: generate self-play games
# (T=1.0 sampling), train candidates, eval vs current best (T=0 argmax),
# promote if avg win rate > 55% across both seat orders.
#
# Bump the gen number every iteration. Reuse the prior winners as the new
# "current best" inputs.

# --- Step 1: Self-play data generation (5000 games, T=1.0 = sample) ---
./build/riftbound decks/miss_fortune_test.json decks/rengar_test.json -r cards/registry.json \
    --agent1 model:models/miss_fortune/v001.onnx \
    --agent2 model:models/rengar/v001.onnx \
    --temp1 1.0 --temp2 1.0 \
    --games 5000 --threads 8 \
    -o training_data/self_play_gen001/game.bin

# --- Step 2a: Train Miss Fortune candidate (REINFORCE warm-start from v001) ---
python scripts/train_agent.py train-rl training_data/self_play_gen001/ \
    --resume models/miss_fortune/v001.pt \
    --output models/miss_fortune/candidate_gen001.pt \
    --epochs 3 --lr 1e-4 --entropy-coef 0.01 \
    --batch-size 256 --gpu 0 --dataloader-workers 3

# --- Step 2b: Train Rengar candidate (REINFORCE warm-start from v001) ---
python scripts/train_agent.py train-rl training_data/self_play_gen001/ \
    --resume models/rengar/v001.pt \
    --output models/rengar/candidate_gen001.pt \
    --epochs 3 --lr 1e-4 --entropy-coef 0.01 \
    --batch-size 256 --gpu 1 --dataloader-workers 3

# --- Step 3: Candidate evaluation (T=0 argmax, 500 games per seat order) ---
# Miss Fortune candidate vs MF v001 (mirror, both directions)
./build/riftbound decks/miss_fortune_test.json decks/miss_fortune_test.json -r cards/registry.json \
    --agent1 model:models/miss_fortune/candidate_gen001.onnx \
    --agent2 model:models/miss_fortune/v001.onnx --games 500
./build/riftbound decks/miss_fortune_test.json decks/miss_fortune_test.json -r cards/registry.json \
    --agent1 model:models/miss_fortune/v001.onnx \
    --agent2 model:models/miss_fortune/candidate_gen001.onnx --games 500

# Rengar candidate vs Rengar v001 (mirror, both directions)
./build/riftbound decks/rengar_test.json decks/rengar_test.json -r cards/registry.json \
    --agent1 model:models/rengar/candidate_gen001.onnx \
    --agent2 model:models/rengar/v001.onnx --games 500
./build/riftbound decks/rengar_test.json decks/rengar_test.json -r cards/registry.json \
    --agent1 model:models/rengar/v001.onnx \
    --agent2 model:models/rengar/candidate_gen001.onnx --games 500

# --- Step 4: Promotion (manual, based on Step 3) ---
# Average win rate across both seat orders to factor out first-player bias.
#   > 55% → promote:
#       mv models/miss_fortune/candidate_gen001.{pt,onnx} models/miss_fortune/v002.{pt,onnx}
#       (same for rengar)
#   45–55% → ambiguous: generate more data, re-train
#   <45%  → discard. Common causes:
#             * entropy_coef too low → policy collapse → raise to 0.05
#             * lr too high → weights drifted → lower to 5e-5
#             * not enough exploration → raise --temp1/--temp2 to 1.5

# --- Iterate ---
# Loop steps 1–4 with the promoted models as the new "current best".
# Generation N uses v_{N-1} for both data gen and eval. Expect 20–50
# iterations before clear improvement plateaus.
